# HCFTL — Human Centered Frontier Technology Lab

HCFTL is an independent, founder-led applied research lab within the Khadafi personal ecosystem.

Its purpose is to explore how AI can help humans build safer, smarter, more capable systems for the physical world while maintaining clear human authority, evidence standards, safety review, and responsible release practices.

## Current phase

**Phase 0 — Institutional Foundation**

At this stage HCFTL is deliberately not optimizing for project count, demos, or product launches. The focus is to establish the lab itself before opening Experiment 001.

## Source of truth

The institutional source of truth is the **HCFTL Independent Lab Blueprint v1.0 — Founder Edition, September 2026**.

## Institutional doctrine

HCFTL is:

- human-centered;
- evidence-led;
- safety-aware;
- simulation-first where appropriate;
- transparent about limitations and failures;
- open by default only when release is responsible;
- designed to preserve meaningful human authority over consequential autonomous actions.

HCFTL is not a weapons lab, offensive cyber lab, pathogen lab, or a vehicle for autonomous targeting systems.
